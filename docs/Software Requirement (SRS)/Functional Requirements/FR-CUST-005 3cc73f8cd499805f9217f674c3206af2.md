## Overview

This requirement defines the process that allows an authenticated customer to add a new shipping address to their Address Book.

The saved address can subsequently be viewed and used for customer purchasing and checkout activities.

## Description

The system shall allow an authenticated customer to create and save a new shipping address.

The system shall validate the submitted address information before storing it.

The system shall associate the new address with the authenticated customer's account.

## Actors

| Actor Role | Description |
| --- | --- |
| **Customer** | Provides and submits a new shipping address. |
| **System** | Authenticates the request, validates the address information, creates the address record, and returns the result. |

## Preconditions

- The customer has an existing account.
- The customer is authenticated.
- The authentication session is valid.
- The associated customer account exists.
- The system can access the database.

## Trigger

The customer selects **Add Address** and submits a new address.

## Main Flow

1. The customer opens the **Address Book**.
2. The customer selects **Add Address**.
3. The system displays the address input form.
4. The customer provides the required address information.
5. The customer submits the form.
6. The system verifies the customer's authentication session.
7. The system validates the submitted address information.
8. The system creates the new address record.
9. The system associates the address with the authenticated customer.
10. The system returns a successful response.
11. The new address is displayed in the customer's Address Book.

## Alternative Flow

### A1 — Authentication Required

- The customer does not have a valid authentication session.
- The system rejects the request.
- No address is created.

### A2 — Invalid Address Data

- The submitted address information does not satisfy the configured validation rules.
- The system rejects the request.
- No address is created.

### A3 — Customer Account Not Found

- The authenticated session references a customer account that is no longer available.
- The system rejects the request.
- No address is created.

### A4 — Address Creation Failure

- The system cannot persist the address.
- The system returns an appropriate error response.
- No incomplete address record is treated as successfully created.

## Postconditions

### If Successful

- A new address record exists.
- The address is associated with the authenticated customer.
- The customer can view the new address in the Address Book.

### If Failed

- No new address is created.
- Existing saved addresses remain unchanged.

## Business Rules

| Rule ID | Rule |
| --- | --- |
| **BR-CUST-021** | Only an authenticated customer can add an address. |
| **BR-CUST-022** | A new address must be associated with the authenticated customer's account. |
| **BR-CUST-023** | Submitted address information must satisfy the configured validation rules. |
| **BR-CUST-024** | A customer must not be able to create an address under another customer's account. |
| **BR-CUST-025** | An address must not be persisted as successfully created when required validation fails. |

## Validation Rules

Exact address fields and validation constraints are **to be defined during implementation** because they are not specified in the provided PRD/SRS material.

| Field | Validation |
| --- | --- |
| **Authentication Session** | Must be valid and associated with an existing customer. |
| **Address Information** | Must satisfy the configured required fields and validation rules. |
| **Customer Identity** | Must correspond to the authenticated customer. |

## Acceptance Criteria

- An authenticated customer can access Add Address.
- An unauthenticated customer cannot add an address.
- A customer can submit a valid shipping address.
- Invalid address information is rejected.
- The created address is associated with the correct customer.
- A successfully created address appears in the Address Book.
- A failed address creation does not modify existing saved addresses.
- A customer cannot create an address for another customer.
