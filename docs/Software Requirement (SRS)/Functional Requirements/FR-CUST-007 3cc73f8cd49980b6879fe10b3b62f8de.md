## Overview

This requirement defines the process that allows an authenticated customer to designate one of their saved shipping addresses as the default address.

The default address can be used as the customer's preferred shipping address in applicable customer and checkout flows.

## Description

The system shall allow an authenticated customer to set one of their saved addresses as the default address.

The system shall verify that the selected address belongs to the authenticated customer before updating its default status.

When a customer sets an address as the default address, any previously designated default address belonging to the same customer shall no longer be considered the default address.

## Actors

| Actor Role | Description |
| --- | --- |
| **Customer** | Selects one of their saved addresses as the default address. |
| **System** | Authenticates the request, verifies address ownership, updates the default address state, and returns the result. |

## Preconditions

- The customer has an existing account.
- The customer is authenticated.
- The authentication session is valid.
- The associated customer account exists.
- At least one saved address exists.
- The selected address belongs to the authenticated customer.
- The system can access the database.

## Trigger

The customer selects **Set as Default** for a saved address.

## Main Flow

1. The customer opens the **Address Book**.
2. The system displays the customer's saved addresses.
3. The customer selects an address.
4. The customer chooses **Set as Default**.
5. The system verifies the customer's authentication session.
6. The system verifies that the selected address belongs to the authenticated customer.
7. The system removes the default status from any existing default address belonging to the customer.
8. The system assigns the default status to the selected address.
9. The system persists the changes.
10. The system returns a successful response.
11. The updated default address state is displayed to the customer.

## Alternative Flow

### A1 — Authentication Required

- The customer does not have a valid authentication session.
- The system rejects the request.
- No address is modified.

### A2 — Address Not Found

- The selected address does not exist.
- The system rejects the request.
- No address is modified.

### A3 — Address Does Not Belong to Customer

- The selected address belongs to another customer.
- The system rejects the request.
- The address is not modified.
- The system does not expose the other customer's address information.

### A4 — Address Update Failure

- The system cannot persist the default address change.
- The system returns an appropriate error.
- The existing default address state remains unchanged.

## Postconditions

### If Successful

- The selected address is marked as the customer's default address.
- Any previously default address belonging to the customer is no longer the default.
- The customer can identify the new default address from the Address Book.

### If Failed

- The existing default address state remains unchanged.
- No unrelated customer address data is modified.

## Business Rules

| Rule ID | Rule |
| --- | --- |
| **BR-CUST-031** | Only an authenticated customer can change their default address. |
| **BR-CUST-032** | A customer can only set one of their own saved addresses as the default address. |
| **BR-CUST-033** | A customer shall have at most one default address at a time. |
| **BR-CUST-034** | The selected address must belong to the authenticated customer. |
| **BR-CUST-035** | Changing the default address must not modify unrelated customer addresses. |

## Validation Rules

| Field | Validation |
| --- | --- |
| **Authentication Session** | Must be valid and associated with an existing customer. |
| **Address Identity** | Must reference an existing address belonging to the authenticated customer. |
| **Default Address State** | Only one address may be designated as the customer's default address. |

## Acceptance Criteria

- An authenticated customer can set a saved address as default.
- An unauthenticated customer cannot change the default address.
- A customer cannot set another customer's address as their default.
- The selected address becomes the customer's default address.
- Any previously default address is no longer the default.
- The customer has at most one default address.
- A failed update does not leave the customer with an unintended default-address state.
